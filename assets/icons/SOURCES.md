# 界面图标

来源：[Lucide Icons](https://lucide.dev/icons/) / [源码仓库](https://github.com/lucide-icons/lucide)。

图标以 SVG 图片放在本目录，通过 HTML 的 `img` 标签加载，不依赖在线图标服务或字体文件。版本与逐张来源见 `sources.json`。

图形路径保持原样；描边颜色按页面需要设为深色、蓝色或白色。使用时保留随附的 `LICENSE`。上游使用 ISC 许可，其中源自 Feather 的部分图标另附 MIT 许可，完整条款见该文件及 [官方许可说明](https://lucide.dev/license)。
